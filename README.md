# readluck - Landing Page

**Your next book is a lucky pick.**

A simple, responsive landing page for **readluck**, a reading app designed to help readers decide what to read next by turning their personal book queue into a lucky pick.

## About the Project

readluck makes choosing your next book a little more fun. Instead of endlessly browsing your reading list, you can let chance pick a book from your personal library.

This repository contains the static landing page introducing the readluck concept and its planned features.

## Features

- **Responsive design** - adapts to desktop and mobile screens.
- **Product introduction** - explains the readluck concept and its core idea.
- **No external dependencies** - built with standard web technologies.

## Project Status

The landing page is a static product introduction and concept prototype. It does not currently include a working waitlist, user accounts, a database, or the readluck mobile application itself.
